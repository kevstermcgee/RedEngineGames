Publish games from this PC

Publishing puts a game on the website and in everyone's app. It needs a GitHub token that may write to kevstermcgee/RedEngineGames, so only the site's owner can publish. Anyone can add games to their own library.

  1. On GitHub: Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: only kevstermcgee/RedEngineGames. Permissions: Contents: Read and write.
  3. Paste the token here.

It is kept on this PC only, in the app's own folder.
