# Physics game experiments

- [`Skyhook Sprint`](projects/skyhook-sprint) — matched aerial-momentum course.
- [`Domino Dynamo`](projects/domino-dynamo) — three physics chain reactions.
- [`Storm Cell`](projects/storm-cell) — recurring-impulse hazard arena.

Each experiment includes authoritative simulation checks and an engine-feedback prompt.

On Windows, double-click `Install-Physics-Game-Shortcuts.cmd` to place launch
shortcuts for all three games on the Desktop. Each project also includes its own
shortcut installer.
