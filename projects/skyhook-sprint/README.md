# Skyhook Sprint

The Red Engine half of the matched Blue/Red physics test. Three authoritative jump pads carry the player through ordered airborne gates; missing a gate breaks the sequence.

## Controls

WASD moves, Shift sprints, Space jumps, and mouse look supplies in-air steering.

## Verify

```sh
RED_HEADLESS=1 scripts/red check
```

Run locally with `scripts/red play-local`.

On Windows, double-click `Install-Desktop-Shortcut.cmd` to place a stable game
launcher on the Desktop.
