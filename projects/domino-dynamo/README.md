# Domino Dynamo

A compact chain-reaction puzzle. Crossing three colored pressure pads applies authoritative impulses to three loose-prop domino banks; the exit resolves only after every bank fires.

## Controls

WASD moves. Step on the red, gold, and blue pads, watch each physics bank fall, then reach the green exit.

## Verify

```sh
RED_HEADLESS=1 scripts/red check
```

Run locally with `scripts/red play-local`.

On Windows, double-click `Install-Desktop-Shortcut.cmd` to place a stable game
launcher on the Desktop.
