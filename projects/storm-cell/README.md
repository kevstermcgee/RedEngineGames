# Storm Cell

A moving-hazard collection game. Four loose crates receive staggered recurring impulses while the player collects three cores and reaches the exit.

## Controls

WASD moves, Shift sprints, Space jumps. Collect every yellow core while avoiding the storm-driven crates.

## Verify

```sh
RED_HEADLESS=1 scripts/red check
```

Run locally with `scripts/red play-local`.

On Windows, double-click `Install-Desktop-Shortcut.cmd` to place a stable game
launcher on the Desktop.
